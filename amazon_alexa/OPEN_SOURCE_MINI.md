## What changed during the hackathon window

The amazon-alexa branch is a new public contribution created during the Amazon Developer Hackathon submission window. It adds a self-hosted MCP implementation for Lead Rescue Voice, Streamable HTTP transport, transparent lead-priority tools, guarded follow-up behavior, an Alexa+ style demo, adversarial tests, protocol-compatibility checks, security scanning, and reusable project-quality tooling.

## How it works

The MCP server exposes tools for ranking leads, inspecting a lead, and preparing a bounded follow-up. Safety-sensitive requests such as a price match fail closed and escalate to the owner. The branch contains runnable source, tests, documentation, and an MIT license inherited from the repository.

## Why it matters

Small service businesses often lose valuable leads because owners are working in the field rather than watching an inbox. The contribution demonstrates an auditable agent pattern that can prioritize opportunities without granting the agent unauthorized pricing or commitment authority.
