# SheetGuard — purchase order duplicate preflight\n\nA working, local-first Excel/CSV preflight screener. This is a **proposed $99 fixed-fee adaptation pilot**, not a completed sale. We screen duplicate identifiers, repeated rows, and same customer/address/amount where these three fields are all present, leaving final decisions to a person. No customer data or account credentials needed for demonstration.\n\n## Run the interactive demo\n\nOpen `index.html` in a browser. Upload `sample-orders.csv` (all people, orders and addresses are fictional); choose columns and click **Analyze duplicates**. The browser version does not send the file to any server. You can export a review CSV.\n\n## Batch scan any XLSX workbook\n\n`python3 sheetguard_xlsx.py orders.xlsx -o review.csv`\n\nPython 3 standard library only; reads first worksheet and writes findings, not edits to orders. Please review all flags before doing anything with orders.\n\n## Demonstration acceptance checks\n\n1. On the fictional sample, flag repeated PO-101, exact duplicate row PO-101, and likely same shipment content under PO-103/104.\n2. The browser ignores incomplete customer+address+total keys for *likely* matches to reduce false positives.\n3. Never edit, delete, or transmit real order data without permission.\n\n## Commercial scope (negotiable, subject to buyer approval)\n\nOne-time $99 scoped pilot: adapt the column mapping and output to a customer's **sanitized** order template, run sample checks, provide a screen-recorded or scripted demonstration, and hand over code and written review instructions.
